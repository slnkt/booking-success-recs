# Успешный экран записи — витамины

Кликабельный прототип по ТЗ «Карточка 1, успешный экран записи»: после записи на сдачу крови клиент видит подборку витаминов и добавляет товары в корзину, не покидая экран.

**Прототип:** https://slnkt.github.io/booking-success-recs/

## Что можно пощёлкать

Кнопка «Настройки прототипа» (справа внизу).

**Состояния**
1. Блок с товарами, корзина пуста
2. Товар добавлен, модалка
3. В корзине уже есть эта позиция
4. Длинный список подготовки + блок — проверка скролла на мобильном
5. Товары не подгрузились — экран как сейчас

**Размещение блока**
- До кнопки «В личный кабинет» (по ТЗ)
- После кнопки — идея для сравнения, если важно не отодвигать основное действие

**Идеи к обсуждению**
- **Тост вместо модалки** — подтверждение снизу экрана, не прерывает: удобнее, когда клиент берёт несколько позиций подряд.
- **Плашка корзины внизу** — после первого добавления внизу закрепляется сумма и кнопка «В корзину», не нужно тянуться к счётчику в шапке.

## Как устроен блок

Карусель из 6 позиций между рекомендациями по подготовке и кнопкой «В личный кабинет». Набор одинаковый для всех, персонализации нет. Ссылка «Все витамины» ведёт в каталог. Подпись «Пригодятся после сдачи крови» снимает конфликт с пунктом подготовки про отказ от витаминов за 24 часа. В карточках короткие названия без повторов «Bioniq» — бренд уже в заголовке блока; полное название остаётся в модалке и корзине.

Добавление — без ухода с экрана: модалка с карточкой товара, суммой корзины и действиями «Перейти в корзину» и «Продолжить» (требование 7). После добавления кнопка на карточке превращается в степпер «− N +», как в маркетплейсах: повторное добавление (требование 9) идёт плюсом без повторной модалки, минус до нуля возвращает кнопку. Счётчик в шапке обновляется с анимацией. В мок-корзине у позиций метка «Источник: успешный экран».

Блок вместе с кнопкой «В личный кабинет» занимает ~370px — кнопка не уходит за пределы первого экрана после рекомендаций.

Мобильная версия приоритетна. Данные моковые.
