# Успешный экран записи — витамины

Кликабельный прототип по ТЗ «Карточка 1, успешный экран записи»: после записи на сдачу крови клиент видит подборку витаминов и добавляет товары в корзину, не покидая экран.

**Прототип:** https://slnkt.github.io/booking-success-recs/

## Что можно пощёлкать

Кнопка «Настройки прототипа» (справа внизу).

**Состояния**
1. Блок с товарами, корзина пуста
2. Товар добавлен, подтверждение
3. В корзине уже есть эта позиция
4. Товары не подгрузились — экран как сейчас

**Размещение блока**
- До кнопки «В личный кабинет» (по ТЗ)
- После кнопки — идея для сравнения, если важно не отодвигать основное действие

**Идеи к обсуждению**
- **Тост вместо модалки** — подтверждение снизу экрана, не прерывает: удобнее, когда клиент берёт несколько позиций подряд.
- **Плашка корзины внизу** — после первого добавления внизу закрепляется сумма и кнопка «В корзину», не нужно тянуться к счётчику в шапке.

## Как устроен блок

Список подготовки с экрана убран — памятка и детали записи уходят на почту, на экране осталась одна строка-напоминание об этом. Освободившееся место занимает карусель витаминов перед кнопкой «В личный кабинет».

Карточки повторяют каталог приложения: тёмная банка на светлой подложке, название комплекса («Сон и спокойствие», «Память и фокус»), цена с подписью «60 капсул» и круглая синяя кнопка добавления. Набор одинаковый для всех, персонализации нет. Ссылка «Все витамины» ведёт в каталог.

Добавление — без ухода с экрана: модалка с карточкой товара, суммой корзины и действиями «Перейти в корзину» и «Продолжить» (требование 7). После добавления круглая кнопка превращается в степпер «− N +»: повторное добавление (требование 9) идёт плюсом без повторной модалки, минус до нуля возвращает кнопку. Счётчик в шапке обновляется с анимацией.

Мок-корзина собрана по реальной: карточка товара с фото, «Сумма заказа» с товарами и доставкой «Рассчитаем позже», строка «К оплате» и кнопка «Оформить заказ». У позиций стоит метка «Источник: успешный экран».

Мобильная версия приоритетна. Данные моковые.
