# Успешный экран записи — витамины

Кликабельный прототип по ТЗ «Карточка 1, успешный экран записи»: после записи на сдачу крови клиент видит подборку витаминов и добавляет товары в корзину, не покидая экран.

**Прототип:** https://slnkt.github.io/booking-success-recs/

## Что можно пощёлкать

Кнопка «Настройки прототипа» (справа внизу).

**Состояния**
1. Блок с товарами, корзина пуста
2. Товар добавлен, модалка
3. В корзине уже есть эта позиция
4. Длинный список подготовки + блок — проверка скролла на мобильном
5. Товары не подгрузились — экран как сейчас

**Размещение блока**
- До кнопки «В личный кабинет» (по ТЗ)
- После кнопки — идея для сравнения, если важно не отодвигать основное действие

## Как устроен блок

Карусель из 6 позиций между рекомендациями по подготовке и кнопкой «В личный кабинет». Набор одинаковый для всех, персонализации нет. Ссылка «Все витамины» ведёт в каталог.

Добавление — без ухода с экрана: модалка с подтверждением, количеством и суммой корзины, действия «Перейти в корзину» и «Продолжить». Счётчик в шапке обновляется, повторное добавление увеличивает количество (на карточке появляется метка «В корзине: N»). В мок-корзине у позиций метка «Источник: успешный экран».

Блок вместе с кнопкой «В личный кабинет» занимает ~370px — кнопка не уходит за пределы первого экрана после рекомендаций.

Мобильная версия приоритетна. Данные моковые.
