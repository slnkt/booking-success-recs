# Успешный экран записи — витамины

Кликабельный прототип по ТЗ «Карточка 1, успешный экран записи»: после записи на сдачу крови клиент видит подборку витаминов и добавляет товары в корзину, не покидая экран.

**Прототип:** https://slnkt.github.io/booking-success-recs/

## Что можно пощёлкать

Кнопка «Настройки прототипа» (справа внизу).

Панель одинаковая с экраном оплаты — те же три группы.

**Формат витрины**
- Карусель — по ТЗ, 5 позиций в один ряд
- Лента вниз — бесконечная прокрутка, как в каталоге маркетплейса: крупные карточки в две колонки с описаниями, порции по 6 позиций подгружаются при подходе к низу, в конце «Вы посмотрели все витамины». В режиме ленты каталог расширен до 18 позиций

**Размещение блока**
- До кнопки «В личный кабинет» (по ТЗ)
- После кнопки — идея для сравнения, если важно не отодвигать основное действие

**Состояния**
1. Блок с товарами, корзина пуста
2. Товар добавлен, подтверждение
3. В корзине уже есть эта позиция

## Как устроен блок

Список подготовки и детали записи (адрес, дата, режим работы) с экрана убраны — всё уходит письмом, на экране осталась одна строка-напоминание об этом. Экран сократился до подтверждения, витрины и кнопки «В личный кабинет».

Раздел называется «Рекомендации к покупке». Карточки повторяют каталог приложения: тёмная банка на светлой подложке, название комплекса («Сон и спокойствие», «Память и фокус»), цена с подписью «60 капсул» и круглая синяя кнопка добавления. Набор одинаковый для всех, персонализации нет. Ссылка «Все витамины» ведёт в каталог.

Подтверждение экрана, витрина и кнопка «В личный кабинет» лежат в одном блоке — без серого разрыва между карточками.

Добавление — без ухода с экрана: тост снизу «Товар добавлен в корзину» с кнопкой «В корзину», исчезает сам через 3,5 секунды и не перекрывает экран. От модалки из ТЗ отказались: она перекрывает экран и на уже завершённом сценарии ничего не даёт. После добавления круглая кнопка превращается в степпер «− N +»: повторное добавление (требование 9) идёт плюсом, минус до нуля возвращает кнопку. Счётчик в шапке обновляется с анимацией.

Мок-корзина собрана по реальной: карточка товара с фото, «Сумма заказа» с товарами и доставкой «Рассчитаем позже», строка «К оплате» и кнопка «Оформить заказ». У позиций стоит метка «Источник: успешный экран».

Мобильная версия приоритетна. Данные моковые.
